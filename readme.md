# Resume Website

A personal resume website built with HTML, CSS, and JavaScript, featuring a bilingual interface, a contact form, and downloadable PDF resumes.

<p align="center">
  <img src="/app/img/baner.png" alt="Resume Website Banner" width="100%">
</p>

## Features

- **Bilingual Interface** — Switch between English and Ukrainian versions of the resume.
- **Contact Form** — Send a message directly through the website.
- **PDF Download** — Download the resume in PDF format in English.
- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Clean UI** — Simple and professional layout focused on readability and usability.

## Technologies

- HTML5
- CSS3
- JavaScript

## Getting Started

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Switch between available resume languages, use the contact form, or download the English PDF version.
